## 一、`01_did_staggered.do` 实测数字汇总（交错 DID，N = 3,000）

模拟设定：300 个体 × 10 期平衡面板，队列分别在第 5、7、9 期陆续受处理，另有 90 个体为永不处理对照组；真实处理效应随暴露期数 $k = t - g$ 递增，受处理观测值的真实整体平均处理效应（True DGP Overall Treated ATT）为 **`1.3966`**。

1. **传统静态 TWFE（反面对比，`xtreg y treat x i.t, fe vce(cluster id)`）**：
   - 点估计 `0.9331`（聚类稳健标准误 `0.0631`，$t = 14.79$，95% 置信区间 `[0.8089, 1.0572]`）。
   - 因已处理早期队列在后期被当作对照组（负权重偏误），静态 TWFE 严重向下偏误约 33%，甚至未能覆盖真实 ATT（1.3966）。
2. **Stata 18 内置异质性稳健 DID（正面示范，`xthdidregress ra (y x) (treat), group(id)`）**：
   - 总体聚合估计（`estat aggregation, overall`）：**`1.2735`**（聚类稳健标准误 `0.1007`，$z = 12.64$，$p < 0.001$，95% 置信区间 `[1.0761, 1.4709]` 覆盖真实参数 `1.3966`）。
   - 动态事件研究估计（`estat aggregation, dynamic`，导出 `Fig_DID_EventStudy.png`）：
     - 事前各期 $k \in [-7, -1]$ 均围绕 0 波动（例如 $k=-3: -0.0633$, $k=-2: 0.0494$, $k=-1: 0.1361$，95% 置信区间均包含 0）；
     - 事后效应随暴露时长稳步攀升：$k=0$ 为 `0.3850`（`0.1084`），$k=1$ 为 `0.8932`（`0.0968`），$k=2$ 为 `1.3587`（`0.1320`），$k=3$ 为 `1.8782`（`0.1352`），$k=4$ 为 `2.2496`（`0.2134`），$k=5$ 达 `2.4697`（`0.1992`），精准贴合真实生成机制。

### 五要素解读示范（Table A1 与 Figure A1）

- 回答了政策在分期交错且效应随时间动态递增时，传统 TWFE 与异质性稳健估计器在识别净效应上的差异。表 A1 与图 A1 显示，静态 TWFE 将总体 ATT 严重低估为 0.933（SE = 0.063），而 `xthdidregress` 给出 1.274（SE = 0.101，95% 区间 `[1.076, 1.471]`），且事件研究图在干预前保持近零平滑并在干预后呈线性爬坡轨迹；需注意图中展示的是逐点 95% 置信区间，且实际研究仍须配合 `honestdid` 评估平行趋势潜在偏离界限，不得把事前近零直接当作平行趋势的绝对证明。

## 二、`02_iv_2sls.do` 实测数字汇总（IV / 2SLS，N = 2,000）

模拟设定：存在未观测正向混杂因子 $U$ 同时推高 $D$ 与 $Y$，真实因果参数（LATE）为 **`1.500`**。

| 表 A2 列号 | 模型设定 | 核心估计量 | 稳健标准误 | 第一阶段有效 $F$ / AR $F$ | 观测值 / $R^2$ |
| :--- | :--- | :--- | :--- | :--- | :--- |
| `(1)` | OLS (`y ~ d + x`) | `d = 2.0384***` | `(0.0234)` | — | `2,000` / `0.823` |
| `(2)` | 第一阶段 (`d ~ z + x`) | `z = 0.6002***` | `(0.0211)` | 一阶段 $F = 809.74$ | `2,000` / `0.320` |

| `(4)` | 2SLS (`y ~ x \| d = z`) | `d = 1.4326***` | `(0.0503)` | 一阶段 $F = 809.74$ | `2,000` / `0.766` |

- 内生性检验（`estat endogenous`）：稳健得分 $\chi^2(1) = 218.237$（$p < 0.0001$），拒绝 $D$ 为外生的零假设。
- Lee et al.（2022, *AER*）$tF$ 门槛核查：一阶段稳健 $F = 809.74$ 远超无需膨胀标准误的 `104.7` 临界值，同时简约式 Anderson-Rubin 检验 $F = 263.27$（$p < 0.0001$）。

### 五要素解读示范（Table A2）

- 回答了在存在正向内生混杂下利用外生工具变量 $Z$ 识别 $D$ 对 $Y$ 局部因果效应的效果。表 A2 第（1）列 OLS 因正混杂偏误将系数高估至 2.038（SE = 0.023），第（2）列证实工具 $Z$ 每提高 1 单位使 $D$ 增加 0.600（第一阶段 $F = 809.74$，远高于 104.7 阈值），第（4）列 2SLS 将估计纠偏至 1.433（SE = 0.050，95% 区间 `[1.334, 1.531]`），成功覆盖真实参数 1.500；识别边界在于 2SLS 仅代表随工具 $Z$ 变动的依从群体局部平均效应（LATE），且实际论文中仍必须从制度逻辑层面独立论证 $Z$ 满足排他性限制。
