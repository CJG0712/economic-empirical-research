# `ols_nlsw88_exemplar.do` 实测输出与五要素解读基准

本输出记录经 **Stata/MP 18.0 for Windows (64-bit x86-64), Revision 07 Jun 2023** 实际运行验证，并通过 `scripts/audit_stata_log.py` 与 `scripts/check_replication_package.py --strict` 零报错、零警告审计。

## 一、数据审计与缺失核验发现

- 原始数据集 `nlsw88.dta` 含 2,246 条观测值、17 个变量，主键 `idcode` 唯一（`isid` 通过）且 `wage > 0`。
- 核心解释变量 `union` 缺失 368 条（占比 16.38%），`occupation` 缺失 9 条，`grade` 缺失 2 条。
- 缺失选择检验（`ttest wage, by(union_miss) unequal`）：非缺失组（1,878 人）平均小时工资 7.565 美元，缺失组（368 人）为 8.795 美元（差异 -1.230 美元，Welch 稳健检验 $t = -2.1916$，$p = 0.0290$），提示存在系统性高薪样本缺失边界。
- 通过动态宏锁定共同分析样本 $N = 1,867$（非工会 1,408 人占 75.4%，工会 459 人占 24.6%），分析样本对数小时工资均值 `1.892`。

## 二、实测核心数字汇总

- **Table 1（分组描述统计，自动导出 `.txt` 与 `.tex`）**：
  - 工会组平均小时工资 8.690 美元（对数 2.062，标准差 0.449），非工会组 7.218 美元（对数 1.837，标准差 0.526），`dtable` 检验与日志补充 Welch 不等方差 $t$ 检验均给出 $p < 0.001$（`ln_wage`: $t = -8.9333$；`wage`: $t = -6.5860$）。
  - 工会组受教育年限更高（13.582 年对比 13.031 年，Welch $p = 0.0002$）、工作经验略长（13.268 年对比 12.701 年，Welch $p = 0.0208$）、南部比例更低（29.6% 对比 46.7%，$p < 0.001$）、都市区比例更高（76.9% 对比 68.7%，$p < 0.001$）。
- **Table 2（OLS 渐进控制，含 `Occupation FE` 勾选行与 `Dep. var. mean = 1.892` 行，自动导出 `.txt` 与 `.tex`）**：
  - 模型 `(1)` 无控制变量：`1.union = 0.2251***`（稳健标准误 `0.0252`，$t = 8.94$，$p < 0.00001$，95% 置信区间 `[0.1757, 0.2745]`），换算为 `25.25%`，调整后 $R^2 = 0.035$。
  - 模型 `(2)` 纳入教育、经验二次项、种族与地域：`1.union = 0.1398***`（`0.0219`，$t = 6.37$，$p < 0.00001$，95% 置信区间 `[0.0968, 0.1829]`），换算为 `15.01%`，调整后 $R^2 = 0.409$。
  - 模型 `(3)` 进一步控制 13 个职业虚拟变量（`Occupation FE = Yes`）：`1.union = 0.1753***`（`0.0220`，$t = 7.95$，$p < 0.00001$，95% 置信区间 `[0.1321, 0.2185]`），换算为 `19.16%`，调整后 $R^2 = 0.461$。

## 三、五要素标准解读示范与坏控制边界

1. **Table 1 与 Figure 1**：回答工会与非工会女性在工资分布及基础特征上是否存在系统差异。表 1 与图 1 显示工会组工资不仅均值高出约 0.225 个对数点，核密度分布亦整体右移且低薪左尾更窄，同时两组在受教育年限和地区分布上显著不平衡（$p < 0.001$），说明原始工资差混杂了地区与人力资本因素；该描述仅针对 1,867 名完整观测样本，不能作因果推断。
2. **Table 2 与 Figure 2**：回答控制可观测人力资本、地域与职业结构后工会溢价是否留存。第（2）列使溢价从 0.225 个对数点（25.25%）收敛至 0.140 个对数点（15.01%），而第（3）列引入职业固定效应后回升至 0.175 个对数点（19.16%，95% 区间 `[0.1321, 0.2185]`），反映工会女性更集中在基线工资偏低的职业。关键边界在于两重约束：第一，职业选择可能与工会加入联立决定，`i.occupation` 存在“处理后/联立坏控制”张力，故第（3）列仅作“职业内部条件比较”；第二，横截面仍未消除个人不可观测能力且高薪工会缺失样本已被排除，因此 19.16% 是清晰边界内的条件关联而非因果效应。
