# 阶段四：经济学论文撰写与中英文期刊体例路由（v1.0 完整版）

本模块规范从实证输出向可投稿学术论文的转化全流程，支持 **英文国际顶刊（`EN-Top5`）** 与 **中文权威期刊（`CN-Top`）** 双轨体例切换，杜绝“工作流水账拼贴”与“空洞 AI 套话”。

动笔前先确定 `Venue Profile`（并在 [research_contract_template.md](../resources/research_contract_template.md) 锁定），正文结构、引文格式与制表细节均随之自动切换：

| :--- | :--- | :--- |

| 附录与复现要求 | 主文只留核心 5–8 张表与 4–6 张图，海量稳健性全部卸载至 **Online Appendix**；强强制 AEA Data & Code Policy | 稳健性表格主文可保留关键汇总表，其余放“附表”或网络附录；同步准备可公开脱敏脚本与说明文档 |

## 二、防拒稿（Desk-Reject-Proof）的经济学论文展陈结构

论文叙事顺序严格遵循“读者认知逻辑”而非“Stata 代码运行顺序”：

### 1. 引言五段式黄金蓝图（通用骨架，依轨道调篇幅）

1. **Hook 与核心张力**：用反直觉事实、重要市场失灵或迫切政策权衡直接入题，坚决不用“随着经济快速发展/人工智能日新月异”等空话开篇。
2. **明确的研究问题与外生抓手**：一句话亮出本文检验的因果或结构问题，说明依托何种独特数据颗粒度与识别设计克服了既有内生性困境。
3. **核心定量发现与经济量级（先声夺人）**：直接汇报基准估计点估计、相对基准均值的百分比幅度与核心稳健边界，同时概括 1–2 个经检验支持的核心机制与异质性分化。
4. **一般均衡/福利含义（视主题适用）**：如有成本收益或社会福利估算，简洁点出政策含义（例如 MVPF、替代与溢出净效应）。
5. **与最接近文献的精确对话与贡献**：分 2–4 个紧密群组对比最近似研究，说明本文不是简单复刻或换样本，而是在估计量口径、识别可信度或机制切割上跨出了哪一步。

### 2. 制度背景与理论假说（Identification-Anchored Institutional Background）

- **制度背景不是百科全书**：只保留直接服务于以下三项任务的制度细节——（a）解释外生变异为何独立于潜在结果或未被事前预料；（b）排查同期混淆政策或阈值操纵风险；（c）界定参数量纲与外部适用边界。多余的法规历史条文一律删简或放附录。
- **理论模型与假说联动**：直接衔接阶段一推导的可证伪推论，使假说编号与后文主表/机制表一一对应。

### 3. 数据、样本形成与描述性事实

- 在正文或首表交代样本起止期、原始观测量、每步筛除标准及样本损耗（可配合漏斗表与缺失选择检验），明确锁定共同样本。
- 用表 1 与 1–2 张基础分布/趋势图揭示处理组与对照组在基线或原始走势上的核心差异，自然引出必须控制混杂或采用准实验设计的必要性。

### 4. 实证策略、基准结果与识别诊断

- 写清具体回归方程与所有下标（个体 $i$、时间 $t$、地区 $c$、队列 $g$）、固定效应组合、权重与标准误聚类层级，并逐条对照声明依赖的识别前提。
- 先报告表内核心系数的**经济量级与物理意义**，再交代标准误、置信区间与统计显著度。紧接主表展开针对核心识别威胁的诊断（例如事件研究图与 `honestdid` 灵敏度、一阶段有效 $F$ 与 AR 区间、密度平滑与带宽对比）。

### 5. 稳健性、机制检验与扩展讨论

- **稳健性按“具体威胁归类”而非按“检验列表堆砌”**：如分小节回应“遗漏变量与同时期政策冲击”“测量误差与函数形式（含零值稳健替代）”“样本选择与推断稳健性”。
- **主文与在线附录（Main Text vs. Online Appendix）分配原则**：主文表格只保留回答核心识别与经济故事不可或缺的证据（一般主文 5–8 张表、4–6 张图）；高维替代稳健性、全套分组详情、长变量定义与辅助安慰剂检验统一归入附录，在主文用 1–2 句概述后索引至 `Appendix Table A.X`。

### 6. 经济意义与福利/政策核算（Economic Magnitude & Welfare Checklist）

每一篇高质量实证论文在结尾或主结果后必须完成至少两项“量级锚定”，避免“仅有星号没有经济学分量”：
1. **基准规模比**：效应占控制组/基线均值或样本标准差的百分比；
2. **历史/跨组差距解释力**：该效应能解释多大比例的城乡、性别、技能或区域既有差距（例如“解释了样本期工薪差距扩大的 18%”）；
3. **成本收益或政策性价比（如数据允许）**：估算单位财政支出、减排吨数或每受惠个体的净收益、无谓损失或边际公共资金价值（MVPF）。

## 三、数字零误差准则与学术去 AI 味黑名单

### 1. 数字溯源铁律

正文、摘要、引言剧透与图表注记中出现的每一个 $N$、系数、标准误、$p$ 值、置信区间与换算百分比，必须逐字溯源至最新实跑的 Stata `.log` 与导出表文件（可在 [research_contract_template.md](../resources/research_contract_template.md) 登记台账）。

### 2. 中英文经济学论文 AI 套话黑名单与替换规范

写作成文与润色阶段，检索并清除下表左侧套话，改写为右侧精准克制的学术表达：

| 禁用的 AI 空洞与夸大套话 | 顶刊/权威期刊替换写法 |
| :--- | :--- |
| 随着数字经济/人工智能的蓬勃发展，全球经济正经历深刻变革…… | 过去十年间，……技术已在……行业迅速渗透，由此引发……分配与效率张力（直接点出具体事实或数据）。 |
| 本文首次提出 / 填补了国内外研究空白 / 具有重大的理论与现实意义 | 据笔者检索所及，现有针对……的研究多聚焦于……；本文在此基础上进一步考察……（若无全覆盖依据，不使用“首次”“空白”）。 |
| 实证结果表明，核心变量在 1% 水平上显著促进了……，证明了因果关系 | 在平行趋势（或排他性）假定成立下，第（3）列估计表明……平均提高 0.140 个对数点（约 15.01%，$SE = 0.022$）。 |
| 本文进行了一系列稳健性检验，结果均高度稳健，充分验证了结论的可靠性 | 为排查……潜在混杂与……测量口径敏感性，表 X 报告了……替代设定；核心估计维持在……至……区间内。 |
| 为政府制定相关政策提供了重要抓手与理论支撑 / 具有重要抓手作用 | 在当前样本所覆盖的……制度区间内，上述估计提示……成本收益权衡；跨地区外推仍受限于……。 |
| *It is worth noting that / In today's rapidly evolving landscape / delves into / sheds light on / underscores the pivotal role of* | 直接主语切入：*We estimate... / Consistent with... / A key caveat is that... / Figure X shows that...* |
